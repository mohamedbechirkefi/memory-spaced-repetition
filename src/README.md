# src/

Python package `memory_research`: `models` (forgetting curves, retrieval update), `config`, `items` (difficulty, common random numbers), `schedules`, `simulate`, `metrics` (validation, metrics), `stats`, `schema`, `environment` (provenance), `guard` (freeze check), `runner`, `report`, `cli`. `reference` is a naive simulator used only by differential tests.
