# MEMORY: forgetting and learning schedules

**Question.** Which review schedule maximizes modelled delayed recall under a fixed study budget?

**Status: protocol frozen v1.1 (owner-approved 2026-11-24; round-3 pre-data amendment: central retention interval 281 days), M3 not started.** No confirmatory experiment has been run and no finding exists. Two simulation parameters (initial half-life and its spread) are calibrated to the public Duolingo spaced-repetition traces (Settles 2017, CC BY-NC 4.0, downloaded by `scripts/download_duolingo.py`, never committed); exploratory runs under `results/exploratory/` are not results. Neither forgetting model predicts real first-review recall better than a constant (CAL-002), so every result will be a property of the assumed memory model, not of human learners.

## Why it matters

Spaced-repetition tools decide when to review each item. Published memory models (exponential and power-law forgetting with updates after each retrieval) make it possible to compare schedules exactly, inside the model, with the review budget held fixed. MEMORY is a simulation study: it makes no claim about human learning gains. Its only real data are public, pseudonymous Duolingo learning traces, used in aggregate to calibrate two parameters; no row-level data is committed.

## What is implemented

A Python package `memory_research` (`src/`): exponential and power-law forgetting, multiplicative retrieval updates, synthetic item difficulty with common random numbers, five schedules (uniform baseline, expanding, massed, Leitner, greedy with matched or misspecified model), run validation, versioned JSON results and run manifests, a report generator and a CLI. A test suite in `tests/` (unit, property, hand-computed and differential tests). No demo yet.

## Quick start

`uv sync --frozen`, then `uv run python -m memory_research test` and `uv run python -m memory_research smoke`. The smoke run is exploratory.
